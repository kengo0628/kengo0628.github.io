# ポケモンフレンダ データベース構築プロジェクト

## 現状の進捗
1. **スクレイピングスクリプトの作成 (`scrape_frienda.py`)**
   - 指定されたWebページからデータ（名前、ID、画像URL）を取得しました。
   - `frienda_images/` フォルダに画像をダウンロードしました。
   - `frienda_database.csv` に基礎データを保存しました。

2. **確認事項**
   - 詳細なステータス（HP, ATK, ポケエネなど）はHTML上には存在せず、**画像の中に埋め込まれています**。
   - そのため、これらの数値を抽出するには「画像認識（OCR）」が必要です。

## 次のステップの選択肢
このデータベースを完成させるために、数値をどうやって読み取るか決める必要があります。

### A案: 高精度AI（OpenAI APIなど）を使う (推奨)
- 画像をGPT-4などのAIに送って読み取らせます。
- **メリット**: 非常に高精度。「素早さ」の矢印や特殊なフォントも読み取れます。
- **デメリット**: APIキーが必要です（数円程度かかります）。
- **手順**: もしAPIキーをお持ちなら、それを組み込んだスクリプトを作成します。

### B案: 通常のOCR（Tesseract）を使う
- Google製の無料OCRツールを使います。
- **メリット**: 無料。
- **デメリット**: インストール作業が必要です（Macなら `brew install tesseract`）。精度はAIより劣り、レイアウトズレに弱いです。
- **手順**: ターミナルで `brew install tesseract` を実行し、ライブラリをセットアップします。

### C案: 手動入力 (確実)
- 現在16枚程度ですので、CSVを見ながら手動で入力するのも現実的です。
- 将来的に数百枚になる場合は自動化が必要です。

## 実行方法
```bash
python3 scrape_frienda.py
```
これを実行すると、最新の情報を取得して `frienda_database.csv` を更新します（既存のデータは上書きされるので注意してください）。
