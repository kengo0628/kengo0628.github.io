# 無料で使えるOCR（文字認識）の代替案

Gemini API（クラウドAI）以外で、無料で利用できる主な手段は以下の「ローカル実行型ライブラリ」です。API制限を気にせず何枚でも処理できますが、導入に少し手間がかかるのと、**「画像内のアイコン（タイプなど）」の認識は難しい**というデメリットがあります。

## 1. EasyOCR (推奨)
PythonベースのDeep Learning OCRライブラリです。日本語の認識精度が比較的高く、手軽に使えます。

- **メリット**: 
    - 完全無料（自分のPCで動くため）
    - 日本語に対応
    - Pythonだけで完結する（`pip install easyocr`）
- **デメリット**: 
    - 処理が少し重い（CPU/GPUを使う）
    - **「アイコンの意味」は理解できない**（「炎のマーク」を「炎」という文字には変換してくれません。「文字」として認識できる場所だけ抽出します）
    - そのため、タイプや特殊技の判定は別途「画像マッチング処理（OpenCVなど）」を作る必要があります。

## 2. Tesseract OCR
Googleが開発している老舗のオープンソースOCRエンジンです。

- **メリット**:
    - 非常に軽量で高速
    - 完全無料
- **デメリット**:
    - 精度の調整が難しい（ノイズに弱い）
    - 別途ソフトのインストールが必要（`brew install tesseract`）
    - EasyOCR同様、アイコン認識はできません。

## 3. OCR.space (無料API)
Webベースの無料APIサービスです。

- **メリット**:
    - APIなのでインストール不要
- **デメリット**:
    - **1日500リクエストまでの制限**がある（Gemini無料枠よりは緩いかもしれません）
    - 精度はそこそこ

---

## 結論とおすすめ
「API制限を完全に回避したい」のであれば、**EasyOCR** への切り替えが最も現実的です。
ただし、**「タイプのアイコン」や「特殊なマーク」を読み取る機能は失われる（または実装が非常に難しくなる）** 点にご注意ください。

「文字データ（HPなどの数値、名前）」だけで良ければ、EasyOCR版のスクリプトを作成可能です。いかがなさいますか？
